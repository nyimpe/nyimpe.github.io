# 2D 인디게임 개발 방향 시장 경쟁력 분석

조사·작성일: 2026-10-19, Asia/Seoul.

- 게시 경로: `/posts/2d-indie-game-development-choice-2026/`
- 전제: 1~4명 범위, 기준팀은 전일제 2명, Windows Steam 유료 1인용, 2D, 검증 뒤 본 제작 12~18개월
- 결정: `고래바다 줄당김`의 6주 회색상자만 우선 승인
- 본 제작 상태: 미승인. 6주판 통과 뒤에도 12~16주 버티컬 슬라이스, 공개 데모, 수요·손익 게이트가 남는다.
- 차선책: 팀의 강점이 턴제 수치 시스템에 있거나 줄당김의 핵심 검증이 두 번 실패하면 `불숨 도깨비가마`의 2주 검증판을 별도로 평가. 자동 전환하지 않는다.
- 결과물의 성격: 시장 조사와 기존 기획을 연결한 제품 가설. 판매 예측·투자 권유·실제 플레이테스트 결과가 아니다.

## 판단 방식

현재 게시 73개와 삭제 이력 80개, 합계 153개 기획의 반복 결정 경계를 확인했다. 그중 이번 팀·플랫폼·기간 조건에 가까운 여섯 후보를 심층 비교했다. 나머지 147개가 모두 중복이거나 탈락했다는 뜻은 아니다. 이번 후보표는 아래 다섯 항목을 1~5점으로 평가한다.

| 항목 | 비중 |
| --- | ---: |
| 무음 10초 전달력 | 20% |
| 시스템의 콘텐츠 증식력 | 20% |
| 1~4명 팀의 제작 통제력 | 25% |
| 반복 중심 결정의 차별성 | 20% |
| 시장 인접성 | 15% |

가중 합계는 구현·사용자 검증 전 의사결정용 휴리스틱이며 성공 확률이나 예상 매출이 아니다. 줄당김 85점과 가마 84점은 같은 A 검증군이다. 시장 인접성은 대표작의 성과가 메커닉의 인과관계를 증명하지 못한다는 한계 때문에 15%만 반영했다. 점수·가중치·후보별 근거·확신 수준·전환 조건은 `decision-matrix.json`에 구조화했다.

## 추천 제품

> 체력바 대신 물결·입질·장력을 읽어 감기·풀기·각도를 바꾸고, 잡은 뒤 보관·나눔·방생으로 다음 바다를 바꾸는 12~18분 2D 낚시 시뮬레이션.

- 핵심 루프: 신호 판독 → 장력 제어 → 포획
- 정리 루프: 완성판에서는 보관·나눔·방생 가운데 하나를 골라 다음 출항의 어종·관계·위험 예고를 변경
- 진행: 공격력 상승보다 약한 진동·깊은 그림자 같은 정보 채널 추가
- 6주 회색상자: 임시 미술 1종, 행동 원형 3개, 세 신호·세 입력, 8~10분 출항, 보관·방생과 다음 판 변수 1개, 행동 기록
- 통과 뒤 12~16주 버티컬 슬라이스: 만 1곳, 어종 8종, 미끼 3종, 날씨 2종, 은혜 사건 3개 검토
- 비목표: 배 운전 오픈월드, 식당·요리, 농사, 생존 제작, 협동·온라인, 여러 지역, 대량 퀘스트, 장비 등급 파밍

## 검증 원칙

6주 회색상자에서 무음 10초 이해, 신호를 이용한 행동 변화, 자발적 재출항을 확인한다. 핵심 폐기 게이트 세 가지는 평균으로 상쇄하지 않고 모두 통과해야 한다.

- 처음 보는 목표 이용자 20명 중 14명 이상이 핵심을 `신호에 따라 감기·풀기·각도를 바꾸는 낚시`라고 설명
- 행동 원형마다 두 정책에 동일 시드 30회씩을 써 신호 대응 포획률이 `계속 감기`보다 20%p 이상 높거나, 차이가 5%p 이내인 같은 포획률에서 중앙 포획 시간이 25% 이상 짧음
- 외부 20~30명 중 40% 이상이 권유 없이 두 번째 출항을 시작

설명과 행동을 분리한다. 70% 이상이 세 번 시도 뒤 두 신호를 말하고 다음 같은 신호에서 입력을 바꾸며 의도적으로 한 번 이상 줄을 풀어야 한다. 보관·방생 층만 실패하면 생태 층을 줄이되 낚시 핵심을 자동 폐기하지 않는다.

본문의 40% 재출항, 공개 데모 60% 핵심 도달·40% 완주·25% 즉시 재시작 같은 수치는 업계 평균이 아니다. 콘텐츠를 더 만들기 전에 멈출지를 정하는 미검증 내부 게이트다. 2주차 수정 뒤 6주차 최종 게이트가 실패하면 한 번만 더 최대 2주간 핵심을 수정하고 새 표본으로 재검증한다. 그래도 세 폐기 게이트 중 하나가 실패하면 줄당김 가설만 기각한다. 가마는 가마 1기·구역당 그릇 1개·행동 4개의 2주 프로토타입을 따로 통과해야 한다.

본 제작 전 손익분기 판매량은 `((개발비 + 마케팅비) × 1.2) ÷ 보수적 순수익/장`으로 계산한다. 본 제작은 데모 행동과 손익을 모두 통과하고, 상점 관심·크리에이터 반응 가운데 사전에 등록한 최소 하나를 통과할 때만 승인한다.
