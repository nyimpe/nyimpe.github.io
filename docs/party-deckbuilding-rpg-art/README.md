# 파티·덱 구축·원정 RPG 플레이 컨셉아트

- 게시글: `posts/party-deckbuilding-rpg-concepts/index.html`
- 공개 이미지: `public/images/party-deckbuilding-rpg/concept-01.webp` ~ `concept-06.webp`
- 생성 방식: 내장 `image_gen`, 기획별 개별 프롬프트로 새 이미지 생성.
- 전체 프롬프트: `prompts.json`
- 최종 이미지와 원본의 크기·해시·파일 기록: `manifest.json`
- 웹용 출력: 원본의 전체 구도를 보존하고 최대 960×540 범위로 축소한 WebP.

| 번호 | 기획 | 그림에서 확인할 핵심 선택 |
| --- | --- | --- |
| 01 | 유언 집행 길드 | 회수 계약에 따른 운반자와 퇴로 방어 |
| 02 | 서약도시 | 양쪽 치료 강화와 적 보급 상자 차단 |
| 03 | 마지막 불을 옮기는 사람들 | 교량 기술자가 복구하는 경로와 조명 포기 |
| 04 | 여덟 초 원정대 | 일시정지 상태의 방어 파괴·끌어당기기·보호 예약 |
| 05 | 귀환자의 지도 | 전투와 귀환 경로가 공유하는 밧줄 한 개 |
| 06 | 괴이 사냥꾼 | 종을 파괴하지 않고 침묵시켜 무적 해제 |

모두 창작 기획을 설명하는 AI 이미지이며 실제 실행 화면이나 완성된 게임 에셋이 아니다. UI 수치와 표현은 시안이며 정확한 규칙은 게시글을 기준으로 확인한다.
