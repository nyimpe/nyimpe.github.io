# 로블록스 2D → 3D 기획 검토

2026-10-22. 기존 11개 기획 글을 13개로 보강했다. 새 게임명은 붙이지 않고 원작 레퍼런스로 구분한다.

- `concepts.json`: 13개 안의 원작 규칙, 3D 공간, 반복 판단, 한 장면, 실패·복구, 소셜, 모바일, 재방문, 시제품, 위험, 출처.
- `market-check.json`: 사용자 제공 시장 수치의 발표 시점·표본·공식/민간 구분 및 확인 한계.
- `local-verification.json`: 빌드, 링크, 원래 앵커 보존, 모바일·테마·홈 진입 검증 결과. 외부 HTTP 200은 응답 확인이며 콘텐츠 사실 검증을 대신하지 않는다.

## 검토 반영

- 호러·서바이벌 각 2안, 타운 RP 2안, 스포츠·레이싱·수집육성·퍼즐·샌드박스·스토리 각 1안, 추가 아케이드 액션 1안.
- Monster Rancher 대신 초기 게임보이 Pokémon을 사용했다. Theme Hospital, Ghost Trick을 추가하고 Rampart의 건축·공격·복구를 보강했다.
- Sweet Home 도구 대체, 채굴 지층 귀환 보존 등 원작과 설계의 오류를 수정했다.
- 독립 검토에서 발견한 동시 도구 사용의 1인 대체, 사다리 1인 운반, 원반 소유권 예시, 장터 주민·손님 RP를 보완했다.
- 확인되지 않은 시장 전체 공급 부족·경쟁작 부재·정해진 개발 기간·매주 자산 추가 약속은 제거했다.

## 확인 범위

기획과 게시물 검증이다. Roblox 런타임, 실제 모바일 게임 조작, 네트워크 성능, 재미·균형·리텐션·결제는 아직 시험하지 않았다. 인원·시간·콘텐츠 수와 수익안은 설계 가설이다.

기존 글과 같은 텍스트 중심 형식을 유지했다. 새 이미지 생성은 하지 않았다. 기존 고양이·아이콘과 공통 스타일을 사용한다. `.claude/`는 이번 작업과 무관한 기존 미추적 폴더라 수정·커밋하지 않았다.
