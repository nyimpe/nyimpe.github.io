- 주인공: 은회색 줄무늬 고양이, 하얀 주둥이, 긴 줄무늬 꼬리, 자주색 작업 조끼와 주황 반다나.
- 중심: 고정된 벽돌 극장집 → 도시의 수직 공간 탐험 → 태엽 배우·소리·장치 발견 → 순서 카드로 공연 창작.
- 비교 기획: 뿌리별 균사정원은 강아지·지하 생태계·빛과 습도의 연결을 중심에 둔다.

## 기획의 범위

현재 결과물은 HTML 기획 게시글과 AI 플레이 컨셉아트이며 실행 게임이나 제작된 게임 에셋이 아니다. 여섯 지역·120종·사계절은 전체 비전이다. 첫 시제품은 두 지역·12종·게임 속 7일, 6×4칸 무대·배우 2·장치 2·순서 카드 4개로 제한한다. 모든 수치는 검증 전 설계 가설이다.

수집 합계는 배우 24 + 장치 18 + 소리 24 + 배경 18 + 역할 18 + 이야기 18 = 120이다. 시제품은 각각 2 + 2 + 3 + 2 + 1 + 2 = 12다. 수집률은 지역·결말 조건이 아니다.

## 이미지와 재현 자료

- `prompts.json`: 생성 전에 저장한 장면별 정확한 프롬프트 6개.
- `generated-sources.json`: 내장 image_gen이 반환한 원본 PNG 경로·SHA-256·크기·바이트 수. 원본은 해당 Codex 생성 폴더에 보존했다.
- `manifest.json`: 게시용 파일의 경로·크기·바이트 수·SHA-256·해시 URL·본문과 일치하는 alt.
- `public/images/alleymoon/scene-01.webp`–`scene-06.webp`: 게시용 이미지 6장.

모든 이미지는 내장 image_gen을 장면마다 한 번 호출해 생성했다. 별도 CLI/API·이미지 생성 모델 대체·코드로 그린 대체 이미지는 사용하지 않았다. Pillow WebP quality=90, method=6으로 내보냈으며 리사이즈·크롭·의미적 편집을 하지 않았다. 최종 출력은 모두 1672×941이다.

여섯 장면은 극장의 아침, 지붕 경로와 풍경, 종시계 집 기어와 새 배우, 무대 편집, 기능별 수집 보관실, 가을 저녁 공연이다. 생성된 각 이미지를 직접 확인해 같은 주인공·벽돌/청록/자주 팔레트·탑다운 게임 화면·상호작용과 UI가 보이는지 확인했다. 영어 UI는 시안이며 실제 규칙은 본문에 있다. 특히 편집 이미지의 START/CHIME/WINGS/LIGHT는 압축 표현이므로 본문에서 시작 버튼과 실제 이동·날갯짓 카드를 분리했다. 저녁 이미지의 관객 수는 확장 분위기 표현이고 실제 규칙은 최대 네 명으로 본문에 명시했다.

## 내용 검토

무대 순서를 풍경 → 이동 → 날갯짓 → 조명에서 조명 → 이동 → 풍경 → 날갯짓으로 바꿀 때 실제 표현이 달라지는 예시를 넣었다. 레일에 탑승한 배우의 점유 예외, 기어 2→1→3의 연결 원리, 비용·시간·체력·공연 시계 정지·녹화와 지원금 중복 방지 규칙을 명시했다.

독립된 봄 4일 계산 예시의 결과는 코인 20 + 12 = 32, 부품 2 + 4 + 2 − 2 = 6, 체력 60 − 4 − 6 + 10 = 60이다. 실제 구현이나 플레이테스트로 검증한 결과가 아닌, 제시한 가정의 산술 검토다.

스타듀 밸리 공식 About(<https://www.stardewvalley.net/about/>)은 생활의 자유·계절·관계·집의 축적을 설명하는 참고 자료다. 제목·도시·인물·소품·무대 규칙·이야기는 새 창작 제안이다. 기존 세 게시글과 이미지는 수정하지 않았다.

사이트 빌드·실제 브라우저·게시 후 검증은 루트 작업에서 수행하고 별도 검증 기록으로 남긴다. 이 문서는 실행 게임이 존재하거나 출시되었다고 주장하지 않는다.
