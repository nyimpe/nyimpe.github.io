- 게시물: `posts/warmrest/index.html`

## 기획 범위

검은 고양이가 내륙 화산 고원의 산마을에서 작은 온천집을 꾸리는 독립 생활·탐험 게임 기획이다. 허브 재배, 온도·광물·향의 배합, 쉬는 공간의 배치, 산속 발견, 네 이웃과의 관계를 하나의 생활로 연결한다. 스타듀 밸리의 생활 축적과 계절·관계 구조를 참고하며, 물결우체국의 섬·조수·배달·항로 복구와 구별한다. 실제 게임 구현은 이번 작업에 포함하지 않는다.

전체 비전은 사계절과 두 탕, 온실, 추가 산지 탐험이다. 첫 시제품은 봄 7일 콘텐츠, 검은 고양이, 네 칸 정원, 단일탕, 두 배합 계열과 두 온도, 네 주민, 네 방 동굴과 한 지름길로 한정한다. 7일은 게임 속 콘텐츠이며 개발 일정이 아니다. 본문의 수치와 통과 기준은 구현 후 검증할 설계 가설이다.

| 장면 | 읽을 행동과 선택 |
| --- | --- |
| 01 | 아침 허브 물주기와 작은 온천집의 생활 동선 |
| 02 | 민트 2·광물 1, 온도 38도 배합을 선택하는 작업대 |
| 03 | 광물 채취와 새 식물 조사, 계단 귀환길이 있는 산속 갈림길 |
| 04 | 가림막 배치와 조용한 탕·이야기 탕의 공간 구분 |
| 05 | 저녁 찻방에서 부엉이와 함께 쉬거나 혼자 쉬는 관계 선택 |
| 06 | 겨울 온실 수확과 서로 다른 휴식 공간으로 보이는 생활의 축적 |

## 이미지 기록

여섯 이미지는 실제 실행 화면이나 개별 타일·스프라이트가 아닌 AI 플레이 컨셉아트다. 게임 화면 구도, 동물 캐릭터와 상호작용, HUD를 검토하는 용도다. 영어 UI와 장식 표지는 임시 표현이고 정확한 규칙은 한국어 본문을 따른다. 03의 새 식물과 04·06의 두 탕·겨울 온실은 전체 비전을 보여준다. 한글 UI, 고정 타일 격자, 캐릭터 크기와 통일된 패널은 시제품 단계의 제작 대상이다.

원본 PNG는 Codex 생성 폴더에 보존했다. 저장소에는 같은 1672×941 전체 구도로 WebP(quality 90) 변환한 6장을 저장했다. 크기 변경·자르기·리터칭·내용 수정 없이 웹용 포맷 압축만 했다. 여섯 호출 모두 첫 시도에서 완료했다.
