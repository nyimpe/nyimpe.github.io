# 작은 발자국 — 생활형 던전 RPG 기획

2026-10-23 KST. 사용자가 범위를 **상세 기획안 + 플레이 컨셉 아트**로 확정했다.

- 게시글: `posts/pawprint-expedition/index.html`
- 이미지: `public/posts/pawprint-expedition/home-concept.png`, `dungeon-concept.png`
- `prompts.json`: 내장 image_gen에 전달한 최종 프롬프트 원문.
- `art-log.json`: 원본 경로, 치수, 크기, 해시, 시각 검토와 한계. 생성 원본을 변형 없이 프로젝트에 복사했다.
- `sources.json`: 레퍼런스와 기술 후보의 공식 출처, 확인일, 해석 범위.
- `verification.local.json` / `verification.live.json`: 실제 게시물 검증 기록. 게임 런타임 검증이 아니다.

## 설계의 중심

강아지 또는 고양이 모험가가 거점에서 준비하고, 던전에서 재료와 수집품을 얻고, 장비와 집을 바꾸는 반복 구조다. 첫 15분, 식사와 경로 선택, 전투, 가방, 패배, 하우징, 낚시, 저장, 실시간 협동 확장, 시제품 범위와 검증 기준을 정의했다.

수치와 시간은 미검증 가설이다. 실제 조작 가능한 게임·실제 휴대폰 입력·성능·재미·온라인 접속은 이번 작업에서 구현하거나 검증하지 않았다. 기획 페이지의 반응형 검증과 혼동하지 않는다.

## 이미지 검토

거점: 고양이 한 명, 낚시터, 요리대, 제작대, 전시 유물, 작은 집과 던전 진입로.
던전: 강아지 한 명, 일반 적 2종, 바닥 공격 예고, 자원, 갈림길, 터치 HUD.
두 장 모두 방향 제시용 생성 컨셉이다. 엄격한 저해상도 픽셀 격자, 타일 이음새, 실사용 스프라이트 애니메이션을 검증하지 않았다. 일러스트의 시점과 세부 밀도는 실제 타일 에셋 제작 시 단순화해야 한다. 원본은 보존하고 미달 사항을 합격으로 바꾸지 않았다.

## 저장소 범위

기존 사이트 구조와 테마, 글쓰기 목록을 재사용했다. 기존 생활·원정 관련 두 기획 글을 확인했으며 모든 과거 기획의 신규성을 주장하지 않는다. 기존 미추적 `.claude/` 폴더는 변경과 커밋에서 제외한다.
