# 인디 시장에서 찾은 어울의 다른 게임 6종

조사·작성일: 2026-10-17, Asia/Seoul.

- 게시 경로: `/posts/eoul-indie-market/`
- 세계관: `/posts/korean-folklore-eoul/`
- 조건: 2D 픽셀아트, 기존 141개 기획과 다른 중심 반복 행동, 인디 시장 근거와 한계, 구체적인 규칙·예시·실패·성장·첫 제작 범위
- 결과물은 기획 포스트다. 게임 구현과 사용자 플레이테스트는 수행하지 않았다.

## 선정과 자료

`market-sources.json`은 2025~2026 Steam 출시 분석과 참고작의 공식 발표·상점 지표를 기록한다. 출시 수, 리뷰 1,000개 도달, 동시접속, 위시리스트, 누적 플레이어, 제출 리뷰는 단위와 기간이 다르므로 합산하거나 인기 순위로 만들지 않는다. 리뷰·동시접속은 2026-10-17의 관측값이며 이후 바뀐다.

참고작의 성과가 특정 메커닉의 성공 원인을 입증한다거나 새 기획의 판매를 보장한다고 해석하지 않는다. 특히 `players`는 판매량이 아니며 무료 데스크톱 게임의 동접은 유료 수요가 아니다.

## 중복 감사와 규칙 교정

`prior-concept-audit.md`는 기존 감사 135항목에 직전 인기 장르 기획 6개를 더한 141항목의 범위와 새 기획의 경계를 기록한다. 소재나 장르 이름이 아니라 한 판 내내 반복하는 결정으로 비교했다.

출고 전 일관성 검토에서 다음을 교정했다.

- 낚시의 입질·물결·장력이 각각 행동·방향·위험을 담당하도록 분리하고 방생 은혜에 상한을 둠
- 먹선 도구와 교차 문맥을 고정하고 모든 결과를 확정 전 미리 보여 줌
- 소문의 두 시간대 비용, 한 단계 변형, 반복 경로 제거, 밤 판본의 동률 처리를 명시
- 훈련의 무시와 반례를 분리하고 입양을 포획·판매가 아닌 상호 선택으로 정의
- 해체의 무료 되감기를 없애 되감기 시간 보너스와 붕괴 수용 보상이 경쟁하도록 함
- 셈알을 30초 단위의 나눌 수 없는 1~3 묶음으로 만들고 정확수 자동 잠금을 추가

## 이미지

내장 imagegen으로 게임별 한 장씩 생성한다. 최종 파일은 `public/images/eoul-indie-market/`의 1536×864 RGB WebP 6장이다. `art-*.json`에 정확한 프롬프트, 생성 원본, 최종 파일, 치수·해시, 변환법, 육안 검토를 기록한다. `manifest.json`은 최종 파일에서 다시 계산한 크기·해시 목록이다. 원본 PNG와 브라우저 검증 화면은 gitignored `logs/eoul-indie-market/`에 보관한다.

이미지는 작동 게임의 캡처가 아니다. 각 게임의 반복 판단과 UI를 보여 주는 구성 예시이며, 이미지의 HUD 수치·세부 표현보다 게시글의 규칙이 우선한다.

## 검증 기록

게시 전 `git diff --check`, Vite 빌드, 로컬 HTTP 상태, 링크·목차 대상, 이미지 해시·자연 크기, 1440/768/390/320px 가로 넘침, 키보드 목차 이동, 테마 전환, 홈페이지와 글쓰기 필터 연결을 확인한다. 결과는 `verification.local.json`에 기록한다.

푸시 후 GitHub Pages 워크플로 성공과 실제 공개 주소의 본문·홈 링크·배포 CSS/JS·6개 이미지·모바일 레이아웃·콘솔을 별도로 확인한다. 공개 검증 결과는 gitignored `logs/eoul-indie-market/live-verification.json`에 남긴다. 웹 게시 검증과 게임 플레이테스트를 구분한다.
