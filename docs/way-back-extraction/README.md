# 귀로 — 격자 이동 하드코어 탈출 로그라이크 기획

2026-10-23 KST. 요청한 다섯 조건(2D 픽셀아트 스프라이트, 바람의나라·어둠의 전설식 이동, 레벨업·파밍·성장·탐험, 총 없는 타르코프식 전투, 디아블로 하드코어)을 하나의 규칙으로 묶은 기획안이다. 글은 `/posts/way-back-extraction/`에 있다.

- 이동: 4방향 격자, 한 칸씩 실시간, 바라보는 방향의 앞 칸만 공격. 인접 4칸만 피격, 대각선은 서로 안전, 복도는 한 명씩.
- 전투: 피해 종류(베기·찌르기·타격) 대 방어구 등급(천·가죽·사슬·판금), 부위 4곳과 출혈·골절·통증, 기력, 방패 또는 횃불, 기술 6종 중 3슬롯, 소리 반경.
- 원정: 제한 시간 20분, 입구 3곳, 조건이 다른 탈출구 5종, 고정 뼈대 + 무작위 살, 원정 변수 4종, 보안 주머니 2칸, 기본 보급.
- 죽음: 캐릭터 영구 삭제(레벨·능력치·숙련·기술·소지품). 창고·천막·상인 신뢰·지도 지식·명부는 야영지에 남는다. 회수 의뢰와 완화 손잡이를 문서에 명시했다.
- 성장: 캐릭터 층(빠르게 쌓이고 죽으면 0)과 야영지 층(느리게 쌓임)의 분리.
- 그림 2장은 글 안의 인라인 SVG(격자 전투 규칙, 첫 지역 지도 뼈대)이며 AI 생성 이미지는 쓰지 않았다.
- `sources.json`: 참고 링크와 확인 결과.
- `verification.local.json`: 빌드·구조·브라우저 화면·테마·목차·홈 필터 확인.

## 범위

기획안만 작성했다. 게임 런타임, 실제 조작감, 밸런스, 재미, 온라인은 검증하지 않았다. 세계관은 한 문단과 세 규칙으로 제한했고, 수치는 모두 플레이테스트 전 가설이다. 저장소의 묘수(턴제)와 작은 발자국(생활형, 죽어도 집이 남음)과는 실시간 격자·영구 죽음·제한 시간 탈출이라는 점에서 겹치지 않는다.
