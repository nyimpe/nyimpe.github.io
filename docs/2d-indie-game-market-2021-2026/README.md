# 2021~2026 2D 인디게임 시장 조사

조사·작성일: 2026-10-18, Asia/Seoul.

- 게시 경로: `/posts/2d-indie-game-market-2021-2026/`
- 범위: 2021-01-01~2026-10-18에 출시된 작품을 중심으로 한 PC·Steam 시장
- 대상: 독립 인디 우선, 2D 자산이 핵심인 하이브리드와 인디 스타일 비교군은 별도 표시
- 결과물: 공개 자료를 정리한 시장 조사 글. 판매 예측, 투자 권유, 게임 플레이테스트가 아니다.

## 조사 원칙

`market-sources.json`은 연도별 공급, 시장 집계, 장르 표본, 공식 흥행 발표와 Steam 리뷰 스냅샷을 구조화해 보존한다.

- 판매량, 플레이어 수, 제출 리뷰, 동시접속, 위시리스트는 서로 다른 지표다. 합산하거나 같은 순위로 만들지 않는다.
- 제작사·퍼블리셔·Valve의 발표를 우선하고, SteamDB·VG Insights 기반 분석은 집계 방식과 한계를 함께 적는다.
- Steam 리뷰는 2026-10-18에 전체 언어·모든 구매 유형으로 확인한 값이며 이후 변한다.
- SteamDB의 `2D`는 사용자 태그다. 순수 2D 게임 수나 시장 매출이 아니다.
- 대표작은 서로 다른 표현과 플레이 구조를 보기 위한 사후 선별 사례다. 특정 메커닉이 흥행의 원인임을 증명하지 않는다.
- DAVE THE DIVER는 Nexon 산하 MINTROCKET 작품이므로 독립 자본 인디가 아니라 인디 스타일 비교군으로만 사용한다.

## 핵심 관찰

- SteamDB 기준 `2D` 태그 출시작은 2021년 4,604개에서 2025년 9,092개로 97.5% 증가했다. 같은 기간 Steam 전체 출시작은 89.5% 증가했다.
- Video Game Insights의 넓은 정의에서는 인디가 2024년 Steam 판매 수량의 58%, 패키지 매출의 48%를 차지했지만, Black Myth: Wukong과 Palworld까지 포함한다. 소규모 팀의 비중으로 읽을 수 없다.
- 2025년 출시작을 같은 시점에 비교한 분석에서는 20,282개 중 608개, 약 2.99%가 리뷰 1,000개에 도달했다.
- 로그라이크 덱빌더, 경영, 시뮬레이션은 비교 표본에서 상대적으로 높은 도달률을 보였고, 2D 플랫포머와 퍼즐은 공급 대비 낮았다. 장르의 실제 성공 확률은 아니다.
- 사례에서 반복된 것은 2D 자체보다 짧게 설명되는 중심 행동, 조합·성장, 재시작 동기, 강한 시각 정체성, 두 플레이 루프의 연결이다.

게시 전 Vite 빌드, 로컬 HTTP 상태, 목차·내부 링크, 1440/768/390/320px 레이아웃, 표 내부 스크롤, 라이트·다크 테마, 홈페이지와 글쓰기 필터 노출, 브라우저 콘솔을 확인한다. 결과는 `verification.local.json`에 기록한다.
