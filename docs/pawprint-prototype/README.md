# 작은 발자국 — 브라우저 시제품

2026-10-23 KST. `posts/pawprint-expedition/`(기획)의 첫 실행 가능한 시제품.

- 게시글: `posts/pawprint-prototype/index.html`
- 게임 본체: `public/posts/pawprint-prototype/play.html`. 의존성 없는 단일 HTML. 글의 iframe과 전체 화면 링크 양쪽에서 같은 파일을 연다.
- 화면: `public/posts/pawprint-prototype/{village,fishing,home,dungeon}.png`. 데스크톱 Chrome의 실제 캔버스 화면을 960×640 영역으로 잘라 1.4배 장치 픽셀로 저장했다(1344×896).
- `design.md`: 핵심 루프, 시스템 범위, 정식 개발 권장 스택, 멀티플레이 대비 원칙, 마일스톤.

## 검증 기록

데스크톱 Chrome에서 게임 상태를 직접 조작해 확인한 항목.

| 항목 | 결과 |
|---|---|
| 키보드 이동 | 0.4초 아래 입력에 28px 이동 |
| 나무 채집 | 목재 +2, 타일이 그루터기로 바뀜(45초 뒤 복구) |
| 베리 채집 | 베리 +2, 빈 덤불로 바뀜 |
| 낚시 | 찌 → 입질 → 미니게임 → 잉어 획득 |
| 요리 | 구운 생선 제작, 먹으면 최대 HP 30→40 버프 120초 |
| 가구 | 의자 제작 → 손에 들기 → 집 바닥 (6,5)에 설치 → 저장 데이터에 남음 |
| 던전 생성 | 1층: 바닥 259칸, 광맥 9, 상자 3, 던전 버섯 4, 적 8, 시작 칸은 사다리 |
| 공격 | 슬라임 HP 9→6 (기본 공격력 3) |
| 사망 | 2층에서 쓰러지면 집으로, HP 전부 회복, 골드 100→80, 저장된 HP도 회복값 |
| 세로 뷰포트 | 390×844 iframe에서 배율 2, 내부 해상도 195×422, 스틱과 A·B 버튼 하단 표시 |

하지 않은 것: 실제 휴대폰 기기 입력·성능·사파리 확인, 재미·수치 균형, 온라인 접속. iOS 시뮬레이터는 이 Mac에 Xcode가 없어 쓰지 못했다.
