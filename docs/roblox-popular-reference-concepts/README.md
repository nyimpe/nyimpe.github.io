# 로블록스 기획안 발굴 3 — 인기 게임에서 가져온 여섯 방향

2026-10-23 KST. 기존 Roblox 2D 전환 13안과 오토배틀 3안에 이어, 인기 게임의 반복 행동을 참고한 독립 후보 여섯 개를 정리했다. 첫 후보는 함께 만든 코스를 직접 달리는 장애물 대결, 두 번째는 주제별 방 꾸미기 경쟁이다.

- `concepts.json`: 출처, 여섯 안의 반복 판단·상태·규칙·예시·복구·모바일·빈 서버·이탈·재방문·시제품·위험·기존 기획과의 비교.
- `roblox-snapshot.json`: 공식 place → universe 확인과 공식 게임 API 응답. `playing`은 조회 순간 인원, `visits`는 중복을 포함하는 누적 방문이다. 고유 이용자나 매출이 아니다.
- `steam-snapshot.json`: 상점의 영어 누적 리뷰 표시와 실패한 전체 언어 API 조회를 함께 보존한다. API는 HTTP 200이었지만 JSON 대신 HTML을 반환했으며 유효한 0건 관측이 아니다. 상점 표본을 전체 언어 리뷰·판매량으로 바꾸어 해석하지 않는다.
- `verification.local.json`: 빌드·구조·브라우저 화면·테마·목차·홈 필터·링크 확인.
- `verification.live.json`: 배포 후 공개 URL의 응답·배포 파일 해시·동일 브라우저 경로 확인. 공개 검증 뒤 추가한다.

## 중복 검토 범위

현재 Roblox 기획 16안의 반복 판단을 읽었다. 삭제 이력은 `fe5e5559^`의 `docs/eoul-new-playloops/prior-concept-audit.md`, `docs/eoul-indie-market/prior-concept-audit.md`, `docs/eoul-popular-genres/prior-concept-audit.md`를 참고했다. 삭제된 모든 원문을 새로 전수 조사한 것은 아니다.

협동 운반과 세척은 과거 「거해 지붕 이삿날」과 「문그림 세척소」 계열을 재검토한 안이다. 정보 분담과 직접 액션도 과거 계열과 겹친다. 이 한계를 본문에 밝히고 신규성 우선순위에서는 첫 두 후보를 앞에 놓았다. 완전히 새로운 장르나 전체 기획 대비 독창성을 주장하지 않는다.

## 형식과 검증 범위

최근 Roblox 두 포스트의 텍스트 중심 형식을 유지했다. 신규 시각 자료는 HTML/CSS로 만든 반복 과정 도식 하나다. 실제 게임 화면·게임 실행·전투 시뮬레이션이 아니며, 새 래스터 이미지나 외부 게임 이미지를 생성·복제하지 않았다. 공통 고양이 이미지와 아이콘을 재사용한다.

원작의 소개와 이번에 제안한 규칙을 구분했다. Unpacking에 시간제한·점수가 있는 것처럼 쓰지 않았고, 싱글플레이 Hades의 공식 규칙과 제안한 협동 방식을 분리했다. 인원·시간·점수·시제품 규모·검증 기준·수익안은 가설이다.

브라우저 자동화는 설치된 Google Chrome을 사용한다. 번들 Playwright의 기본 Chromium 실행 파일이 없어 첫 실행은 실패했고, 설치된 Chrome으로 다시 검사한다. 실제 휴대전화 터치나 Roblox 실행 증거와 구별한다. 기존 Phaser 번들의 크기 경고는 남아 있으며 이 문서 추가로 생긴 경고가 아니다.

Roblox Studio, 경쟁작 직접 플레이, 실제 모바일 입력, 네트워크 물리·저장, 재미·밸런스·잔존율·결제는 검증하지 않았다. 기존 `.claude/` 미추적 폴더는 수정하거나 커밋하지 않았다.
