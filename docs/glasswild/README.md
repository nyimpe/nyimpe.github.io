# 유리사막 도감차 — 기획·플레이 컨셉아트

- 게시물: `posts/glasswild/index.html`
- 공개 주소: https://nyimpe.github.io/posts/glasswild/
- 최종 이미지: `public/images/glasswild/scene-01.webp` ~ `scene-08.webp`
- 생성 방식: 내장 `image_gen`으로 장면별 새 이미지 생성. CLI/API 생성기는 사용하지 않았다.

- 게시물·자산 검증: `verification.json`

## 기획의 중심

선 귀의 적갈색 코기 강아지가 내륙 유리사막을 도감차와 함께 여행한다. 규화목 숲·그늘 협곡·유리사구 등에서 흔적과 조건을 읽고, 생물의 행동과 지형의 비밀을 기록한다. 발견한 지식은 작은 서식 정원, 객차 꾸미기, 동료와의 공동 기록, 다음 탐험의 선택으로 돌아온다.

스타듀 밸리의 자율적인 하루와 계절·관계·생활의 축적을 참고한다. 물결우체국의 배달·섬·조수·항로 복구, 온기골 온천집의 탕 배합·개장·방문료와는 배경과 핵심 행동을 다르게 설계한다. 오래된 지도와 다른 나방의 길을 현재의 식생·바람·밤의 조건으로 이해하는 이야기이며 옛 시설망을 수리하는 이야기가 아니다.

전체 비전은 6개 탐험 지역과 144개 고유 도감 항목이다. 식물 32 + 야생동물 32 + 광물 24 + 화석 16 + 옛 문양 24 + 소리 풍경 16 = 144. 변형 색·관찰 단계·중복 표본은 별도 항목 수로 더하지 않는다. 첫 시제품은 10일 분량 콘텐츠, 2개 탐험 지역과 야영지, 24개 도감 항목, 4명 동료, 3개 생활 모듈로 제한한다. 수치와 통과 기준은 제작 후 검증할 설계 가설이며 게임 구현·플레이테스트는 이번 작업의 범위가 아니다.

## 이미지의 용도와 보존

8장은 실제 게임 실행 화면, 고정 규격 타일·스프라이트가 아닌 AI 플레이 컨셉아트다. 장면별 카메라·캐릭터 크기·UI 아이콘에는 차이가 있다. 화면 속 영어·숫자·도구는 임시 구성이고 확정 규칙은 한글 본문을 따른다. 실제 제작 때 직교 타일, 캐릭터 스프라이트, 공통 패널, 한글 UI를 별도로 통일해야 한다.

생성 원본 PNG는 Codex 생성 폴더에 보존한다. 웹에는 같은 구도와 크기를 유지한 WebP(quality 90)를 저장한다. 자르기·크기 변경·리터칭 없이 포맷 압축만 하며, 게시물이 참조하는 최종 자산은 모두 저장소 안에 둔다. 캐시 갱신을 위해 출력 SHA-256의 앞 12자를 URL 쿼리에 붙인다.
