## 이미지 제작

최종 게시 이미지 위치: `public/images/eoul-game-concepts/`.
각 게임에 내장 `image_gen` 도구로 독립적인 플레이 화면을 생성했다.
CLI/API fallback은 사용하지 않았다. Pillow는 인코딩·크기 조정 용도로만 사용했다.

- `art-01-02.json`: 정확한 프롬프트, 생성 경로, 최종 경로, 크기와 해시, 시각 확인.
- `art-03-04.json`: 동일 정보와 04의 3/6 배부름 표시 수정 프롬프트.
- `art-05.json`: 중단 전 완성한 항해 이미지의 원래 프롬프트와 식별 정보.
- `art-06.json`: 이어서 완성한 남굴 이미지의 프롬프트와 식별 정보.
- `manifest.json`: 최종 배포 이미지 6개의 통합 식별 정보.

이미지는 기획을 설명하는 AI 컨셉 시안이며 실행 화면이나 실제 저해상도 타일셋이 아니다.
03의 생성 격자는 9열×8행으로 보인다. 게시글에 명시한 프로토타입 규격은 8×8이며,
캡션에서 이 차이를 밝혔다. 모든 화면의 세부 UI·숫자·배치는 본문의 규칙이 기준이다.

## 내용 검토

세계관 원문과 현재 사이트 파일을 확인했다. 무작위 수익 예측이나 시장 수치는 넣지 않았다.
게임 수치·세션 길이·사건·동료 능력은 검증 전의 창작 설계로 명시했다.

독립 검토로 다음 항목을 보완했다.

- 약속 선택의 근거가 되는 현재·다음 턴 상대 의도 공개.
- 공주산 이동 시 자신의 이전 점유를 제외한 충돌 판정.
- 불가살이의 크기 제약을 우회하지 않도록 분기 동반 진입과 복귀 불가 예고.
- 항해 예시의 좌표 거리와 식량 비용(관측 8, 잘못 방문 9).
- 남굴 사건의 증거 수와 제출 규칙 일치.

게임을 구현하거나 플레이테스트한 것은 아니다. 게시글·이미지·탐색 링크·반응형 표시와 배포를 확인하는 작업이다.

## 게시 전 검증

- `npm run build` 성공. 기존 Phaser 묶음 크기 경고만 발생했다.
- Chrome에서 1440·768·390·320px 너비 확인, 가로 넘침 없음.
- 여섯 이미지 1536×864 로딩과 HTTP 응답, 파일 SHA-256 일치 확인.
- 목차 전체 앵커, 키보드 이동, 테마 전환, 홈페이지 및 글쓰기 목록 연결 확인.
- 브라우저 오류 없음. 상세 결과: `verification.local.json`.
- 공개 배포 검증은 배포 이후 별도로 수행하며 로컬 검증과 구분한다.
