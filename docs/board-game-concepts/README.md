# 보드게임에서 출발한 게임 기획 9선

- 게시글: `posts/board-game-concepts/index.html`
- 공개 이미지: `public/images/board-game-concepts/concept-01.webp` ~ `concept-09.webp`
- 제작 방식: 내장 `image_gen`으로 기획마다 별도 플레이 컨셉 화면 생성.
- 전체 프롬프트·수정 이력·원본 위치: `art-01-03.json`, `art-04-06.json`, `art-07-09.json`.
- 공개 파일의 크기·해시·버전 URL과 원본 기록: `manifest.json`.
- 웹 출력: 전체 구도를 보존하고 최대 960×540으로 축소한 WebP. `prepare-assets.py`로 생성하고 본문의 크기와 이미지 버전 URL을 동기화.
