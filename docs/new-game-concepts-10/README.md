## 작성 범위

사용자는 앞선 기획과 겹치지 않는 게임 기획 10개를 같은 양식으로 요청했고, 여러 기획을 한 글에 정리하는 형식을 선택했다. 기존 보드게임 9선과 파티 RPG 6선의 비교표·기획별 이미지·소개·규칙·예시·시제품·검증 형식을 사용했다. 최근 생활 기획의 동물 주인공과 픽셀아트 분위기는 유지했다.

기존 9개 기획 글, 총 113개 아이디어를 비교했다. 배송·배합·생태 도감·균사 길·공연·계약·원정·덱·경매·제한 소통 등과 새 기획의 반복 판단을 구분했다. 이는 사이트 내부 중복 확인이며 전 세계 작품에 대한 독창성 증명은 아니다.

## 이미지

기본 제공 `image_gen` 도구로 10개를 각각 생성했다. 04는 배의 화물 위치와 기울기, 05는 두 언어 가설의 화살표 방향을 같은 도구로 수정했다. 각 기록에 이전 원본과 편집 프롬프트를 보존했다. 원본은 도구가 반환한 `.codex/generated_images` 경로에 있고 웹용 최종본은 저장소 안에 보관한다.

원본 구성 비율을 보존해 최대 1280×720, WebP 품질 82로 변환했다. 최종 파일은 모두 1279×720이다. 이미지의 숫자·좌표·격자는 개념 시안이며 본문의 정확한 예시를 대체하지 않는다. 02·08·10 등에는 장면별 읽기 한계도 본문에 표시했다.

## 재생성

저장소 루트에서 `python3 docs/new-game-concepts-10/build-post.py`를 실행하면 본문과 매니페스트를 만든다. 이미지 생성 API를 다시 호출하지 않으며 기존 이미지의 해시와 기록 일치를 검사한다. 이미지가 바뀌면 해당 `art-*.json` 기록도 함께 갱신해야 한다.

## 검증 범위

수치 예시를 별도로 재계산했고, 언어 추론의 인물 이름 선행 단서·고정 노광 마스크·제목 크기와 문구의 독립성을 보완했다. 실제 게임은 구현하거나 플레이테스트하지 않았다.

로컬 글에서 기획 10개·이미지 10개, 고유 ID, 모든 내부 앵커·기존 글 링크, 이미지 HTTP 200 및 저장 해시 일치, 829px 데스크톱과 390px 모바일의 페이지 가로 넘침 없음, 모바일 비교표 가로 스크롤, 테마 전환과 Enter 목차 이동, 이미지 전체 로딩, 콘솔 오류·경고 없음을 확인했다. 홈페이지에서 새 글로 이동하는 경로도 확인했다. `npm run build`가 성공했다. 기존 Phaser 번들에 대한 Vite 크기 경고는 남아 있다.

위 검증 기록은 최초 로컬 작성 시점의 결과이다. 실제 게임 실행 검증이나 GitHub Pages 배포 결과를 뜻하지 않는다.
