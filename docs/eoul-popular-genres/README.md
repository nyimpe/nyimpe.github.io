## 선정과 자료

`market-sources.json`은 대표작 6종의 1차 출처, 지표, 기간, 확인일, 해석의 한계를 기록한다. 동시접속자·누적 판매·누적 이용자·최근 리뷰를 하나의 인기순위로 합산하지 않는다. Steam 중심 표본이며 한국·모바일·콘솔 전체를 대표하지 않는다.

현재 이용 규모, 과거 판매 성과, 지속적인 평가 활동을 확인한 후보 가운데 아래 여섯 방향을 골랐다. 대표작의 성과에서 새 기획으로 넘어가는 판단은 기획적 해석이며 시장 성공의 증명은 아니다.

| 게임 | 중심 행동 | 참고작 |
| --- | --- | --- |
| 설령 첫겨울 | 주민 욕구를 읽고 작업·교대·생활 공간 조정 | RimWorld |
| 장승 모의전 | 전투 사이 구매·저축·이자·출전 배치 | Backpack Battles |

`prior-concept-audit.md`는 12개 과거·현재 포스트의 135항목을 센 기준, 확인한 Git ref, 가장 가까운 구작과의 차이를 기록한다. 삭제된 글은 복원하지 않았다. 모든 요소가 과거와 완전히 겹치지 않는다는 주장은 하지 않는다.

## 이미지

내장 imagegen으로 게임별 한 장씩 생성했다. 최종 파일은 `public/images/eoul-popular-genres/`의 1536×864 RGB WebP 6장이다. 각 `art-*.json`에 정확한 프롬프트, 원본 경로, 변환과 해시, 육안 확인 결과를 남긴다. `manifest.json`은 실제 최종 파일에서 다시 계산한 크기·해시 목록이다. 원본 PNG와 검증 스크린샷은 gitignored `logs/eoul-popular-genres/`에 보관한다.

이미지는 작동 게임의 캡처가 아니다. 장르별 주요 판단을 보여 주는 구성 예시이며, HUD의 수치·정밀 격자·장식 표현보다 게시글의 규칙이 우선한다. 실제 원전 소재와 새로 만든 운영·경기·역할 놀이·물리 규칙도 구분했다.

## 검증 기록

게시 전에 빌드, 로컬 링크·목차 대상, 파일별 이미지 해시·자연 크기, 1440/768/390/320px 화면의 가로 넘침, 키보드 목차 이동, 테마 전환, 홈페이지 및 글쓰기 분류 연결을 확인한다. 결과는 `verification.local.json`에 기록한다.

푸시 후 Pages 워크플로 성공과 실제 공개 주소의 본문·이미지·배포 CSS/JS·목록 연결을 따로 확인한다. 공개 검증 결과는 `logs/eoul-popular-genres/live-verification.json`에 보관한다. 플레이테스트 가설과 웹 게시 검증을 혼동하지 않는다.
