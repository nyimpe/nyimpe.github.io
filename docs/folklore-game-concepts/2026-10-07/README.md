# 한국 괴물·귀신 게임 기획 50선 · 2026-10-07

2026.10.06 글의 공통 세계관과 여섯 섹션 구성을 이어받은 별도 후속 게시물입니다. 기존 43개 기획과 이미지는 보존합니다. 새 50개는 수집 도감에서 실제 확인한 게임 항목과 논리 퍼즐의 규칙을 참고하되, 전승의 성질이 플레이 선택을 바꾸도록 설계했습니다.

- 게시물: `posts/korean-folklore-game-design-50/index.html`
- 기획 원본: `concepts.json`. 루프, 창작 규칙과 승패, 예시, 조작, 최소 데모 범위, 제작 쟁점, 이미지 시점, 대체 설명을 기록합니다.
- 전승 근거: `creature-evidence.json`. 실제 사용한 43개 도감 항목의 현재 설명을 보존합니다. 각 게시물 링크는 원래 항목 ID를 유지합니다.
- 게임 근거: `reference-provenance.json`. 기획마다 수집 데이터의 실제 ID·제목·데이터셋·수집 원문을 기록합니다. 논리 퍼즐 네 종은 기존 규칙 글의 항목으로 연결합니다.
- 생성 기록과 프롬프트: `generation-records.json`. 내장 ImageGen으로 기획별 단일 이미지를 생성했습니다. CLI/API 대체 경로는 사용하지 않았습니다. 원본 경로와 선택된 보정본을 보존합니다.
- 게시용 이미지: `public/images/folklore-game-50/concept-01.webp`부터 `concept-50.webp`까지. 최대 960×540으로 축소하고 WebP 품질 65로 압축합니다. 기존 글 이미지나 다른 도감 에셋을 재압축하지 않습니다.
- 이미지 정보: `manifest.json`. 실제 크기·바이트·SHA-256·내용 해시 URL·생성 원본·검토 범위를 기록합니다.
- 시각 검토: `review-01-10.jpg` 등 다섯 연락 시트. 각 번호는 기획 번호입니다. 컨셉아트의 카메라, 존재의 주요 특징, 핵심 조작 표현을 검토합니다. 시안의 HUD 숫자와 퍼즐 배치는 완성 게임이나 실제 정답 보드의 증거가 아닙니다.

이미지는 실행 가능한 게임의 캡처가 아닌 AI 플레이 컨셉아트입니다. 본문의 수치·장비·승패·추가 퍼즐 조건은 창작 설정입니다. 문헌에 외형이 없거나 서로 다른 이본이 있는 항목은 그 한계를 본문에 표시합니다. 출처 글의 요약과 창작 설정을 별도 목록으로 분리했습니다.

재생성은 `python3 scripts/build-folklore-concepts-50.py`, 새 생성 원본의 게시용 압축은 Pillow가 있는 런타임에서 `python3 scripts/prepare-folklore-concepts-50.py`를 실행합니다. 검증 결과는 `verification.json`에 기록합니다.
