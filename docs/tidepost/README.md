# 물결우체국 기획·플레이 컨셉아트

- 게시물: `posts/tidepost/index.html`
- 공개 주소: https://nyimpe.github.io/posts/tidepost/
- 최종 이미지: `public/images/tidepost/scene-01.webp` ~ `scene-09.webp`
- 생성 방식: 내장 `image_gen`으로 장면별 새 이미지 생성. CLI/API 생성기를 사용하지 않았다.
- 정확한 생성 프롬프트: `prompts.json`
- 원본 경로·크기·SHA-256 및 최종 파일·버전 URL: `manifest.json`
- 원본은 Codex 생성 폴더에 보존한다. 저장소에는 원본 해상도와 전체 구도를 유지한 웹용 WebP를 저장한다.

## 범위

스타듀밸리의 생활 리듬·성장·이웃 관계에서 출발한 독립 게임 기획이다. 고양이 또는 강아지 우편지기가 조수로 길이 바뀌는 동물 섬마을을 연결한다. 생활과 탐험을 동등한 중심 활동으로 다룬다. 다섯 탐험 지역, 환경 퍼즐, 공통 도구, 등불과 귀환 규칙, 발견이 생활에 주는 보상, 배달일·탐험일의 구체적 예시를 포함한다. 첫 7일 시제품에는 물비늘 동굴 다섯 방, 퍼즐 하나, 영구 지름길 하나와 두 발견 보상을 추가했다. 실행 가능한 게임 개발은 이번 산출물에 포함하지 않는다.

## 아트의 용도

모두 AI로 만든 플레이 컨셉 시안이며 실제 실행 화면이나 분리된 게임 에셋이 아니다. 그림 안 영문 UI와 수치는 임시 표현이다. 정확한 조건과 수치는 게시물의 한국어 규칙을 기준으로 한다. 카메라 각도, 캐릭터 크기, HUD 패널과 팔레트의 최종 통일은 시제품 제작 단계에서 검증한다. 웹용 변환은 포맷 압축만 수행하며 내용 편집·크롭·리터칭을 하지 않는다.

## 탐험 보강 기록

- 피드백: 배달 경로 선택에 비해 미지의 지역 탐험과 발견 보상이 부족했다.
- 배달·생활일과 탐험일을 나누고, 단서 → 도구 준비 → 환경 퍼즐 → 추가 탐사/귀환 → 집·마을의 변화로 핵심 구조를 보강했다.
- 마을의 상시 우회로와 야외의 진입 조건을 구분했다. 새 방 조사에 드는 등불, 영구 지도·지름길, 실제 이동·대기 시간을 반영하는 귀환을 정의했다.
- 기존 6개 이미지는 `exploration-baseline.json`에 저장한 SHA-256과 동일하다. 07–09만 새로 생성했다.
- 최종 이미지 9장 모두 1672×941이며 프롬프트·출처·해시·대체 텍스트는 통합 기록을 따른다.
