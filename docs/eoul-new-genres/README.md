## 이미지 출처와 범위

모두 내장 imagegen으로 새로 생성했다. 정확한 프롬프트, 원본 경로·해시, 변환 방식, 육안 확인 결과는 `art-01-02.json`, `art-03-04.json`, `art-05-06.json`에 기록했다. `manifest.json`은 실제 최종 WebP 파일에서 크기와 SHA-256을 다시 읽어 만든 통합 목록이다. 원본 PNG와 확인 스크린샷은 gitignored `logs/eoul-new-genres/`에 보관한다.

최종 이미지는 각각 1536×864 RGB WebP다. 원본에서 크기와 형식을 변환했으며 별도 재합성이나 그림 수정은 하지 않았다. 이미지의 숫자·격자·장식 화살표는 구성 예시이고 판정의 근거는 본문 규칙이다. 실제 구현된 게임의 스크린샷이 아니다.

## 내용 검토

각 게임에 세계관 연결, 조작·규칙, 수치 예시, 실패·성장, 첫 제작 범위와 검증 질문을 포함했다. 상점 보충 작업의 수량 한도, 우편 철거 시 접수시각 보존, 리듬 빈 입력 벌점, 스포츠 그물 반사와 터치 규칙, 관측 주민 소음의 중복 처리까지 검토했다. 장르와 계산에 대한 별도 검토에서도 게시를 막을 오류를 발견하지 못했다.

게임 구현과 사용자 플레이테스트는 수행하지 않았다. 수치·분량·통과 기준은 초기 설계 가설이다. 원전 소재와 이번에 창작한 장치·경기·운영 규칙을 구분했다.

## 게시 검증

- `npm run build`: 성공. 기존 Phaser 번들 크기 경고가 남으며 이번 글이 추가한 실행 코드나 의존성은 없다.
- 본문 내부 및 다른 로컬 글의 링크·대상 앵커를 확인했다.
- 브라우저 확인 결과는 `verification.local.json`에 기록한다: 6개 이미지의 실제 로딩·크기·해시, 1440/768/390/320px 문서 너비, 목차와 키보드 이동, 테마 전환, 홈페이지·글쓰기 분류, 콘솔 오류.
- 푸시 후 Pages 워크플로 성공과 실제 공개 페이지를 별도로 확인한다. 공개 페이지 검증 결과는 `logs/eoul-new-genres/live-verification.json`에 남긴다.
