## 규칙 교차검산

- 취모: 이동 2회로 호흡 `5→3`, 오른손 이동 1회로 오른손 악력 `6→5`; 두 하중 예시의 합은 각각 100%다.
- 청우: 깃발은 `초당 +2×3초=+6`, 방울은 `−10`으로 계산했다.
- 불씨숲: 습윤선 뒤 C2는 `4−2=2`라 D2에만 전달되고, D2는 `1−2=0`으로 멈춘다.
- 답소리: 밀도 2 응답으로 호흡 `6→4`, 모방으로 신뢰 `2→3`, 낮은 밀도로 여백 `1→2`, 낮은 세기로 격앙 `4→3`이다.
- 가마: 윗굴뚝 두 번은 `74/70/61→73/70/65→72/70/69`, 산소 `1→2→3`이며 최대 변화량은 4다.
- 하늘차례: 3턴째 고리는 왼손, 방울은 오른손에 도착하고 횃불은 2턴째 즉시 다시 던져 충돌을 피한다.

## 이미지

내장 imagegen으로 게임별 플레이 화면 한 장씩 생성했다. 최종 파일은 `public/images/eoul-new-playloops/`의 1536×864 RGB WebP 6장이다. `art-*.json`에 정확한 프롬프트, 생성 원본, 최종 파일, 치수·해시, 변환법, 육안 검토를 기록한다. `manifest.json`은 최종 파일에서 다시 계산한 크기·해시 목록이다. 원본 PNG와 브라우저 검증 화면은 gitignored `logs/eoul-new-playloops/`에 보관한다.

이미지는 작동 게임의 캡처가 아니다. 각 게임의 반복 판단과 UI를 보여 주는 구성 예시이며 이미지의 HUD 수치보다 본문의 규칙이 우선한다.
