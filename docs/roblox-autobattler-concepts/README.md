# 로블록스 기획안 발굴 2 — 오토배틀

2026-10-22 KST. 성공 근거가 확인되는 오토배틀 4종을 비교하고, Hearthstone Battlegrounds를 규칙 보조 레퍼런스로 사용했다. Roblox에 적용할 독립 후보 3개와 첫 후보의 구현·검증 범위를 정리했다.

- `steam-snapshot.json`: Steam 공식 리뷰 API의 전체 언어·전체 구매 유형 누적 집계. 긍정률은 positive / total × 100, 소수 첫째 자리 반올림. 판매량 또는 전체 플랫폼 이용자 수로 환산하지 않는다.
- `roblox-snapshot.json`: Roblox 공식 API의 시각별 응답. `playing`은 조회 순간 플레이 인원, `visits`는 중복 방문을 포함하는 누적 방문 횟수. title unavailable/id=0 응답은 유효한 0명 관측이 아니다.
- `research.json`: 공식 자료, 역사적 지표와 현재 집계의 구분, 조사 한계, 기존 기획과의 비교.
- `verification.json`: 실제 수행한 로컬·공개 페이지 검증. Roblox 런타임 검증과 구별한다.

기존 Roblox 기획 글처럼 텍스트 중심으로 작성했고, 배치 설명은 HTML/CSS 도식이다. 실제 게임 스크린샷이나 전투 시뮬레이션이 아니다. 새 래스터 이미지·실행 가능한 Roblox 프로젝트·미검증 전투 코드는 만들지 않았다.

## 범위

요청 제목인 ‘기획안 발굴2’에 맞춘 시장 조사와 구현 기획이다. 구현 완료·재미·수익성·기기 성능·재방문율을 주장하지 않는다. 제안한 인원·시간·유닛 수·테스트 기준은 검증 전 가설이다. 새 게임명은 붙이지 않고 참고작과 반복 판단으로 후보를 구별한다.

현재 첫 Roblox 글의 13개 안 및 현재 게시물의 오토배틀 관련 키워드를 확인했다. 수집 육성 턴제 RPG와 이번 판 안에서 구매·배치를 반복하는 자동전투를 구별했다. 전체 삭제 이력의 모든 기획에 대한 독창성 보증은 하지 않는다.

기존 `.claude/` 미추적 폴더는 이번 변경에 포함하지 않는다.
