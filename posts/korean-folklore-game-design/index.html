1. 자료에서 읽은 것

지난 글의 326항목은 대부분 조선·삼국 문헌의 짧은 기록입니다. 게임 재료로 보면 네 가지가 눈에 띕니다.

  • 약점과 조건이 함께 전한다. 고관대면은 똑바로 바라보자 사라졌고, 거악은 쇠붙이를 두려워하며, 불가살이는 쇠를 먹을수록 커집니다. 야광은 체의 구멍을 세다 날이 밝아 달아납니다. 기록이 곧 공략법입니다.
  • 막는 도구가 체계적이다. 새해 문에 붙인 처용·각귀·닭·호랑이 그림, 금갑장군, 지니면 악한 것을 막는 벽사수처럼 플레이어 쪽 무기와 카드로 옮기기 좋은 항목이 많습니다.
  • 장소가 뚜렷하다. 순천 바다, 단양 동굴 아래의 남굴북벽, 제주의 각씨당, 버려진 원(院) 건물처럼 지역이 맵이 됩니다.
  • 외형 기록이 비어 있는 항목이 많다. 압마처럼 모습이 불분명한 존재는 해석의 여지를 남기지만, 원전에 없는 설정을 사실처럼 덧붙이지 않는 원칙이 필요합니다.

2. 공통 기획: 괴이록(가제)

다섯 컨셉이 공유하는 세계관입니다. 조선의 문헌 속 괴물을 기록하고, 기록된 방법으로 상대하는 사람들의 이야기입니다. 어느 장르로 만들든 괴물 데이터와 아트, 도감을 재사용합니다.

  1. 기록이 곧 힘 — 도감 칸을 채우는 것이 진행이고, 장르마다 도감이 해금 축이 됩니다.
  2. 전하는 약점이 곧 공략 — 원전에 적힌 조건과 약점을 메카닉으로 옮깁니다.
  3. 출처를 지킨다 — 괴물마다 원전과 해설 링크를 달고, 외형이 전하지 않으면 상징으로만 그립니다.

4. 컨셉 다섯 가지

로그라이크 덱빌더 벽사록

문에 붙이던 벽사 그림과 부적으로 덱을 짜서 고을 → 산사 → 바다 → 저승의 밤을 넘습니다.

  • 루프: 갈림길 지도 선택 → 적의 의도가 보이는 턴제 전투 → 부적 획득·강화 → 막 보스 → 판이 끝나면 만난 괴물이 도감에 남음
  • 처용 부적: 역신을 막는 문 그림 → 방어 + 질병형 적 봉인. 전염병 귀신인 두억시니의 카운터
  • 어둑서니: 두려워할수록 커진다는 기록 → 내 덱의 ‘두려움’ 카드 수만큼 적이 강해짐
  • 응시: 바라보자 사라진 고관대면, 노려보자 달아난 독각 → 특정 적에게만 통하는 0코스트 카드
  • 쇠 카드 상성: 거악에게는 공포, 불가살이에게는 먹이 → 같은 카드의 가치가 적에 따라 뒤집힘

참고: Slay the Spire 2, Balatro · 규모: 부적 120장, 적 60종, 보스 6 · 가격대 $15~19.99

불릿 헤븐 야행: 첫닭이 울 때까지

순라군이 되어 도깨비불과 귀신이 쏟아지는 조선의 밤길에서 첫닭이 울 때까지 버팁니다.

  • 루프: 20분 생존 → 엽전으로 레벨업 → 무기 3택 → 진화 조합 → 새벽 보스
  • 무기: 팥, 복숭아 가지, 소금, 방울, 엄나무, 부적. 진화 예: 팥 + 가마솥 → 동지팥죽
  • 도깨비불: 횃불처럼 줄지어 움직인다는 기록 → 일렬 행렬로 돌진하는 적 패턴
  • 불가살이: 쇠를 먹을수록 커짐 → 쇠 무기를 많이 고른 빌드일수록 보스가 강해짐
  • 장승: 네거리의 고정 안전지대. 체를 걸면 야광이 구멍을 세느라 멈춤

참고: Vampire Survivors, Megabonk · 이 사이트의 Vampire Survivor Lite 코드 재사용 · 가격대 $5~9.99

경영·코지 귀객주막

이승과 저승 갈림길의 주막을 물려받아, 낮에는 재료를 모으고 밤에는 한 맺힌 손님을 대접합니다.

  • 루프: 낮 채집(산·바다·장터) → 밤 영업(주문·조리·자리 배치) → 한을 풀면 성불 → 영험으로 주막 증축 → 손님 사연이 도감에 기록
  • 무사귀: 제사를 받지 못한 귀신 → 제삿밥을 차려 달래는 핵심 손님. 늦으면 한 게이지가 차서 재난을 일으킴
  • 흰 여우: 사람의 자리까지 들어와 앉는 여우 → 좋은 자리를 노리는 자리 배치 퍼즐
  • 지귀: 마음의 불길이 몸으로 번진 불귀신 → 뜨거운 음식을 내면 주막에 불이 남
  • 도깨비: 메밀묵을 좋아한다는 민간 속설 → 단골 손님, 대접하면 장터 재료를 가져다줌

참고: Dave the Diver, Spirittea · 가격대 $10~14.99 · 경쟁이 가장 빠르게 늘어나는 장르

크리처 컬렉터 괴물백과: 화첩

화원이 되어 팔도의 괴물을 만나고, 원전에 적힌 기록 조건을 채워 화첩에 그려 넣습니다.

  • 루프: 지역 탐험 → 조우 → 기록 조건 충족(전투만으로는 잡히지 않음) → 화첩 등록 → 동료 편성 → 지역 신령의 시험
  • 고관대면: 똑바로 바라보자 사라짐 → ‘응시’를 세 번 연속 성공해야 기록
  • 각씨: 제물을 가져가 먹는 노란 짐승 → 제물을 두고 숨어 기다리는 잠입 조우
  • 귀구: 붉고 검은 무늬의 개 한 쌍 → 두 마리를 함께 편성하면 집 지키기 협동기
  • 규모 관리: 326항목이 콘텐츠 상한. 첫 출시는 120종, 외형 기록이 없는 항목은 상징형 디자인

참고: Cassette Beasts · 가격대 $20 이상 · 국내 대형사(펄어비스 DokeV, 카카오게임즈 도깨비 IP)와 소재가 겹침

메트로배니아 저승길: 남굴북벽

저승 차사 견습생이 잃어버린 명부를 찾아 단양 동굴 아래 지하세계로 내려갑니다. 쓰러뜨린 괴물의 성질이 새 이동 능력이 됩니다.

  • 독각: 외다리로 뛰어다님 → 2단 점프
  • 망량: 그림자 가장자리에 숨고 그림자보다 앞서 움직임 → 그림자 대시
  • 장비인: 팔이 사람 키의 몇 배 → 갈고리 팔
  • 압마: 주몽이 물 위에서 타고 이동 → 수면 달리기
  • 대오공: 버려진 원의 거대한 지네, 두꺼비가 흰 기운으로 맞섰다는 기록 → 금두꺼비를 데려오면 보스 패턴이 바뀜

참고: Hollow Knight: Silksong, Skul · 가격대 $20 이상 · 레벨 디자인과 애니메이션 부담이 가장 큼

5. 우선순위

  1. 야행 — 기존 Vampire Survivor Lite를 고쳐 픽셀 규격·팔레트·괴물 데이터 구조를 먼저 시험합니다.
  2. 벽사록 — 시장 성과, 민담 적합성, 제작 부담의 균형이 가장 좋아 본 프로젝트 1순위입니다. 첫 목표는 부적 20장, 적 8종, 1막짜리 웹 데모입니다.
  3. 귀객주막 — 도달률은 가장 높지만 경쟁이 빠르게 늘어 출시 시점이 중요합니다. 벽사록의 괴물 아트를 손님으로 재사용합니다.
  4. 괴물백과와 저승길 — 도감 데이터와 아트가 쌓인 뒤의 장기 목표입니다.

모든 컨셉이 지난 글의 326항목을 같은 데이터로 씁니다. 다음 작업은 항목별 속성·약점·출처를 JSON으로 정리하는 일입니다.
