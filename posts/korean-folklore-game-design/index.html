1. 자료에서 읽은 것

지난 글의 326항목은 대부분 조선·삼국 문헌의 짧은 기록입니다. 게임 재료로 보면 네 가지가 눈에 띕니다.

  • 약점과 조건이 함께 전한다. 고관대면은 똑바로 바라보자 사라졌고, 거악은 쇠붙이를 두려워하며, 불가살이는 쇠를 먹을수록 커집니다. 야광은 체의 구멍을 세다 날이 밝아 달아납니다. 기록이 곧 공략법입니다.
  • 막는 도구가 체계적이다. 새해 문에 붙인 처용·각귀·닭·호랑이 그림, 금갑장군, 지니면 악한 것을 막는 벽사수처럼 플레이어 쪽 무기와 카드로 옮기기 좋은 항목이 많습니다.
  • 장소가 뚜렷하다. 순천 바다, 단양 동굴 아래의 남굴북벽, 제주의 각씨당, 버려진 원(院) 건물처럼 지역이 맵이 됩니다.
  • 외형 기록이 비어 있는 항목이 많다. 압마처럼 모습이 불분명한 존재는 해석의 여지를 남기지만, 원전에 없는 설정을 사실처럼 덧붙이지 않는 원칙이 필요합니다.

2. 공통 기획: 괴이록(가제)

마흔세 컨셉이 공유하는 세계관입니다. 조선의 문헌 속 괴물을 기록하고, 기록된 방법으로 상대하는 사람들의 이야기입니다. 어느 장르로 만들든 괴물 데이터와 아트, 도감을 재사용합니다.

  1. 기록이 곧 힘 — 도감 칸을 채우는 것이 진행이고, 장르마다 도감이 해금 축이 됩니다.
  2. 전하는 약점이 곧 공략 — 원전에 적힌 조건과 약점을 메카닉으로 옮깁니다.
  3. 출처를 지킨다 — 괴물마다 원전과 해설 링크를 달고, 외형이 전하지 않으면 상징으로만 그립니다.

6차: itch.io 역대 인기작

itch.io는 다운로드 수를 공개하지 않습니다. 그래서 전체·장르별 최고 평점 목록에 오른 게임을 모아 평가 수로 인기를 비교했습니다(2026년 10월 6일 기준). 전체 최고 평점 목록 첫 화면 36개 가운데 22개가 비주얼 노벨입니다. Steam 지표로는 뺐던 장르가 itch.io에서는 가장 강한 셈입니다. 무료작이 많고 받아서 바로 해 볼 수 있어, 짧은 이야기 게임이 입소문을 타기 좋은 곳입니다. 6차는 앞의 스물여덟 컨셉, 그리고 경영·수집형과 겹치지 않는 다섯 개를 골랐습니다.

4. 컨셉 마흔세 가지

1차 선정

로그라이크 덱빌더 벽사록

문에 붙이던 벽사 그림과 부적으로 덱을 짜서 고을 → 산사 → 바다 → 저승의 밤을 넘습니다.

  • 루프: 갈림길 지도 선택 → 적의 의도가 보이는 턴제 전투 → 부적 획득·강화 → 막 보스 → 판이 끝나면 만난 괴물이 도감에 남음
  • 처용 부적: 역신을 막는 문 그림 → 방어 + 질병형 적 봉인. 전염병 귀신인 두억시니의 카운터
  • 은비녀: 붉은 손이 머리카락을 잡으려다 은비녀 때문에 실패했다는 물귀신 이야기 → 붙잡기·끌어당기기 공격을 한 번 막는 장신구
  • 응시: 바라보자 사라진 고관대면, 노려보자 달아난 독각 → 특정 적에게만 통하는 0코스트 카드
  • 쇠 카드 상성: 거악에게는 공포, 불가살이에게는 먹이 → 같은 카드의 가치가 적에 따라 뒤집힘

참고: Slay the Spire 2, Balatro · 규모: 부적 120장, 적 60종, 보스 6 · 가격대 $15~19.99

불릿 헤븐 야행: 첫닭이 울 때까지

순라군이 되어 도깨비불과 귀신이 쏟아지는 조선의 밤길에서 첫닭이 울 때까지 버팁니다.

  • 루프: 20분 생존 → 엽전으로 레벨업 → 무기 3택 → 진화 조합 → 새벽 보스
  • 무기: 팥, 복숭아 가지, 소금, 방울, 엄나무, 부적. 진화 예: 팥 + 가마솥 → 동지팥죽
  • 도깨비불: 횃불처럼 줄지어 움직인다는 기록 → 일렬 행렬로 돌진하는 적 패턴
  • 불가살이: 쇠를 먹을수록 커짐 → 쇠 무기를 많이 고른 빌드일수록 보스가 강해짐
  • 장승: 네거리의 고정 안전지대. 체를 걸면 야광이 구멍을 세느라 멈춤

참고: Vampire Survivors, Megabonk · 이 사이트의 Vampire Survivor Lite 코드 재사용 · 가격대 $5~9.99

메트로배니아 저승길: 남굴북벽

저승 차사 견습생이 잃어버린 명부를 찾아 단양 동굴 아래 지하세계로 내려갑니다. 쓰러뜨린 괴물의 성질이 새 이동 능력이 됩니다.

  • 독각: 외다리로 뛰어다님 → 2단 점프
  • 망량: 그림자 가장자리에 숨고 그림자보다 앞서 움직임 → 그림자 대시
  • 장비인: 팔이 사람 키의 몇 배 → 갈고리 팔
  • 압마: 주몽이 물 위에서 타고 이동 → 수면 달리기
  • 대오공: 버려진 원의 거대한 지네, 두꺼비가 흰 기운으로 맞섰다는 기록 → 금두꺼비를 데려오면 보스 패턴이 바뀜

참고: Hollow Knight: Silksong, Skul · 가격대 $20 이상 · 레벨 디자인과 애니메이션 부담이 가장 큼

2차 선정

오픈월드 생존 제작 표해록: 이름 없는 섬

표류 기록 속 이름 없는 섬에 떠밀려 와, 섬의 기이한 생물로 살 곳과 배를 다시 만들어 고향으로 돌아갑니다.

  • 루프: 채집·사냥 → 제작·거처 확장 → 밤에는 거인과 짐승이 돌아다님 → 다음 섬으로 항해 → 배를 완성해 귀향
  • 거해: 천 년 묵은 게가 벗은 껍질이 바닷가로 떠밀려 오고, 그 아래 대여섯 사람이 든다 → 첫 거처
  • 근화초: 하루 사이에 싹이 나서 꽃과 씨를 맺고 시든다 → 하루 주기로 거두는 작물
  • 대인: 사람을 잡아먹는 외눈 거인, 흩어진 물건을 정리하느라 추격을 멈췄다 → 쫓길 때 짐을 흩뿌려 시간을 버는 도주
  • 괴외촉천: 바다를 걸어 배를 뒤집으려다 도끼로 팔다리를 치자 물러났다 → 귀향 항해의 마지막 보스
  • 섬 구성: 여인국, 소인국, 흑진인처럼 표류 설화 속 나라가 섬 하나씩. 고산나봉 껍데기로는 짐승을 쫓는 나팔을 만든다

참고: Terraria, Core Keeper · 가격대 $20 이상 · 도달률은 모든 후보 중 가장 높지만 시스템이 많아 제작 부담이 큼

소울라이크 보스 러시 명궁: 화살 한 대

화살 한 대만 가진 명궁이 되어 문헌 속 큰 짐승과 한 마리씩 맞섭니다. 체력 바 없이, 급소에 한 번 맞히면 끝나고 한 번 맞으면 끝납니다.

  • 루프: 보스 선택 → 패턴 관찰 → 한 발 사격 → 빗나가면 화살을 주우러 뛰어감 → 쓰러뜨린 짐승의 기록이 열림
  • 강철: 말 모습은 열기와 가뭄, 소 모습은 폭풍과 우박 → 두 형상을 오가며 아지랑이(조준 흔들림)와 바람(화살이 밀림)으로 판이 바뀜
  • 도전복: 화살을 번번이 피하다가, 한 발 먼저 쏘고 피할 곳을 겨냥한 다음 화살에 잡혔다 → 이 판만 화살 두 대. 첫 발은 미끼
  • 흑호: 무기를 알아채고 피하다가 몰래 숨긴 작은 칼에 제압됐다 → 활을 들면 물러나므로 활을 내려놓고 다가가야 함
  • 천모호: 가죽이 질겨 여러 포수가 못 잡다가 부자가 거듭 쏘아 잡았다 → 2인 협동 전용 보스. 마지막은 이성계 형제 사냥 전설의 독호

참고: Titan Souls, Blasphemous · 가격대 $20 이상 · 보스 10마리 안팎이라 범위를 작게 잡기 좋음

부머 슈터 영제교: 궁궐의 밤

괴이가 들끓는 밤의 궁궐을 빠르게 누비며 활, 조총, 신기전, 부적으로 쓸어 냅니다.

  • 루프: 전각 하나가 한 스테이지 → 색 패(열쇠)를 찾아 문을 엶 → 숨은 통로와 부적 → 전각의 주인 보스
  • 수괴·수류견: 궁궐에서 목격된 개를 닮은 빠른 짐승 → 지그재그로 파고드는 근접 돌격 적
  • 무두귀: 머리 없는 귀신 → 머리 맞히기 보너스가 통하지 않는 적
  • 궁중괴수: 궁궐의 회화나무가 사람처럼 곡했다 → 울음으로 화면을 흔드는 고정 포대형 적
  • 천록: 영제교 석상을 사악한 것을 물리치는 짐승으로 본 기록 → 부적을 바치면 깨어나 잠시 함께 싸움

참고: ULTRAKILL, Ion Fury, Dusk · 가격대 $10~14.99 · 2.5D 레이캐스팅에 2D 픽셀 텍스처·스프라이트

심리 호러 어둑서니

장마철 빈 한옥에 홀로 남은 아이가 등잔 하나로 밤을 버팁니다. 무서워할수록 커지는 그림자 앞에서는 뛸 수도, 등잔을 끌 수도 없습니다.

  • 루프: 방을 하나씩 살핌 → 소리와 흔적으로 정체를 추리 → 문헌에 적힌 대로 대응 → 새벽까지 버팀
  • 어둑서니: 두려워할수록 커진다 → 두려움 게이지가 곧 적의 크기. 뛰거나 뒤돌아보거나 등잔이 꺼지면 오름
  • 홍난삼: 겁내지 않고 다가가자 담을 넘어 달아났다 → 도망치면 쫓아오고 다가가면 물러나는, 직관과 반대인 대응
  • 지하지인: 검은 뼈 같은 다리와 종이 치마만 보이고, 죽은 고모의 목소리로 음식을 요구했다 → 들어줄지 고르는 대화
  • 유계량: 보이지 않는 채 말하고 솥과 밥상을 뒤집었다 → 방을 비운 사이 물건 배치가 바뀌는 환경 공포
  • 협사이함: 대나무 상자 안에서 날뛰다 강물에 던지자 조용해졌다 → 들고 다니면 소리로 위치가 드러나는 처리 퍼즐

참고: Look Outside, The Coma · 3~5시간 분량 · 제작 부담이 가장 낮고 1인 개발 선례가 있음

전술 RPG 팔도 퇴마군

무당, 승려, 포수로 꾸린 퇴마대가 팔도의 마을을 돌며, 적의 다음 행동을 보고 막는 격자 전투를 벌입니다.

  • 루프: 마을 선택 → 적 의도 공개 → 아군 이동·기술 → 적 행동 → 정해진 턴 동안 집과 사람을 지킴 → 퇴마대 성장
