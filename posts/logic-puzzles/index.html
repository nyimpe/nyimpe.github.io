  1. 도형 배치하기

    01. 롤리팝스

    원 하나와 이웃한 막대 하나를 짝지어 사탕을 만들고, 서로 다른 사탕끼리는 변으로 닿지 않게 합니다. 같은 행·열에서 같은 종류의 조각(원·가로 막대·세로 막대) 사이에는 다른 종류의 조각이 있어야 합니다.

    플레이 · 전체 규칙 ↗

  2. 칸 칠하기

    02. 쿠로도코

    숫자는 자기 칸을 포함해 상하좌우로 검은 칸이나 테두리까지 보이는 흰 칸의 총수입니다. 숫자 칸은 흰색으로 유지하고, 흰 칸 전체는 연결되게, 검은 칸끼리는 변으로 닿지 않게 칠합니다.

    플레이 · 전체 규칙 ↗

  3. 칸 칠하기

    03. 비나이로+

    행과 열마다 검은색·흰색 개수를 같게 하고, 같은 색이 세 칸 연속되지 않게 채웁니다. = 기호 양쪽은 같은 색, x 기호 양쪽은 다른 색이어야 합니다.

    플레이 · 전체 규칙 ↗

  4. 칸 칠하기

    04. 음양

    모든 칸을 흰색이나 검은색으로 채워, 각 색의 칸들이 상하좌우로 하나로 이어지게 합니다. 같은 색의 2×2 정사각형을 만들면 안 됩니다.

    플레이 · 전체 규칙 ↗

  5. 단어·체스

    05. 체스 퍼즐

    체스 레인저에서는 체스 기물의 이동법을 따라 매번 다른 기물을 잡아, 마지막에 기물 하나만 남깁니다. 왕도 잡을 수 있습니다.

    플레이 · 전체 규칙 ↗

  6. 칸 칠하기

    06. 온도계

    온도계를 둥근 시작점에서부터 빈틈없이 채우고, 바깥 숫자에 맞춰 각 행과 열의 채운 칸 수를 맞춥니다.

    플레이 · 전체 규칙 ↗

  7. 도형 배치하기

    07. 노리노리

    각 구역에서 정확히 두 칸을 칠하고, 모든 칠한 칸을 1×2 또는 2×1 도미노로 만듭니다. 도미노는 구역 경계를 넘어도 되며, 서로 다른 도미노는 변으로 닿을 수 없습니다.

    플레이 · 전체 규칙 ↗

  8. 칸 칠하기

    08. 모자이크

    숫자가 있는 칸을 중심으로 한 3×3 영역에서, 검게 칠한 칸 수가 그 숫자와 같도록 채웁니다. 숫자 칸 자신도 개수에 포함합니다.

    플레이 · 전체 규칙 ↗

  9. 칸 칠하기

    09. 지뢰찾기

    숫자를 단서로 가로·세로·대각선 이웃 칸의 지뢰 위치를 찾습니다. 숫자는 자기 칸을 제외한 주변 최대 여덟 칸의 지뢰 수를 나타냅니다.

    플레이 · 전체 규칙 ↗

  10. 선 연결하기

    10. 슬랜트

    모든 칸에 두 방향 중 하나의 대각선을 놓고, 숫자가 있는 꼭짓점에 닿는 선 수를 맞춥니다. 선들이 어떤 형태의 고리도 만들면 안 됩니다.

    플레이 · 전체 규칙 ↗

  11. 도형 배치하기

    11. LITS

    각 구역에 L·I·T·S 모양의 네 칸 도형 하나를 칠해, 칠한 칸 전체가 상하좌우로 이어지게 합니다. 회전·반전을 포함해 같은 모양끼리는 변으로 닿을 수 없고, 칠한 2×2 정사각형도 만들 수 없습니다.

    플레이 · 전체 규칙 ↗

  12. 도형 배치하기

    12. 갤럭시

    격자 전체를 원이 하나씩 들어가는 영역으로 나눕니다. 각 영역은 그 원을 중심으로 180° 돌려도 같은 모양이어야 합니다.

    플레이 · 전체 규칙 ↗

  13. 도형 배치하기

    13. 텐트

    나무마다 상하좌우의 텐트를 하나씩 짝짓고, 행·열의 텐트 수를 바깥 숫자에 맞춥니다. 텐트끼리는 대각선까지 서로 닿으면 안 됩니다.

    플레이 · 전체 규칙 ↗

  14. 도형 배치하기

    14. 배틀쉽

    주어진 크기와 수량의 직선 전함을 배치해 행·열에서 배가 차지하는 칸 수를 맞춥니다. 서로 다른 배는 대각선까지 닿으면 안 됩니다.

    플레이 · 전체 규칙 ↗

  15. 선 연결하기

    15. 파이프

    타일을 회전시켜 모든 파이프를 하나로 연결합니다. 순환하는 고리는 만들면 안 됩니다.

    플레이 · 전체 규칙 ↗

  16. 칸 칠하기

    16. 히토리

    일부 숫자 칸을 검게 칠해 각 행·열의 숫자 중복을 없앱니다. 검은 칸끼리는 변으로 닿을 수 없고, 남은 흰 칸은 모두 연결되어야 합니다.

    플레이 · 전체 규칙 ↗

  17. 칸 칠하기

    17. 헤야와케

    방의 숫자만큼 칸을 검게 칠하고, 검은 칸끼리 변으로 닿지 않으며 흰 칸 전체가 연결되게 합니다. 가로·세로로 연속된 흰 칸 줄은 세 개 이상의 방에 걸칠 수 없습니다.

    플레이 · 전체 규칙 ↗

  18. 선 연결하기

    18. 신고키

    모든 원을 지나는 하나의 고리를 그리고, 흰 원에서 직진하며 검은 원에서 꺾습니다. 원의 숫자는 원 양쪽으로 뻗는 직선 구간 길이의 합입니다.

    플레이 · 전체 규칙 ↗

  19. 선 연결하기

    19. 마슈

    모든 원을 지나는 하나의 고리를 그립니다. 흰 원에서는 직진하되 적어도 한쪽 다음 칸에서 꺾고, 검은 원에서는 꺾되 양쪽 다음 칸에서는 직진해야 합니다.

    플레이 · 전체 규칙 ↗

  20. 선 연결하기

    20. 스티치 · 바느질

    인접 구역 쌍마다 1÷는 한 번, 2÷는 두 번, 3÷는 세 번 바느질을 놓고 행·열의 구멍 수를 맞춥니다. 바느질은 서로 다른 구역의 상하좌우 이웃한 두 칸을 잇고, 구멍은 공유할 수 없습니다.

    플레이 · 전체 규칙 ↗

  21. 칸 칠하기

    21. 아쿠아리움

    수족관마다 일정 수위까지 물을 채우거나 비워 두어 행·열의 물 칸 수를 맞춥니다. 한 수족관 안에서는 전체 너비에 걸쳐 수위가 같아야 합니다.

    플레이 · 전체 규칙 ↗

  22. 칸 칠하기

    22. 타파

    검은 칸들을 상하좌우로 연결된 한 덩어리로 만들되, 2×2 검은 영역은 만들지 않습니다. 단서는 주변의 연속된 검은 구간들의 길이이며, 서로 다른 구간 사이에는 흰 칸이 있어야 합니다.

    플레이 · 전체 규칙 ↗

  23. 도형 배치하기

    23. 스타 배틀

    각 행·열·구역에 지정된 개수의 별을 배치합니다. 별끼리는 가로·세로·대각선으로 서로 닿을 수 없습니다.

    플레이 · 전체 규칙 ↗

  24. 칸 칠하기

    24. 카쿠라스

    검은 칸의 위치 값을 더해 각 행과 열의 바깥 숫자를 맞춥니다. 행에서는 열 번호, 열에서는 행 번호가 칸의 값이며 첫 번째 칸부터 1, 2, 3으로 셉니다.

    플레이 · 전체 규칙 ↗

  25. 숫자 채우기

    25. 스카이스크래퍼

    N×N 격자에 높이 1~N의 건물을 넣고, 각 행과 열에서 같은 높이가 겹치지 않게 합니다. 바깥 숫자는 그 방향에서 보이는 건물의 수입니다.

    플레이 · 전체 규칙 ↗

  26. 숫자 채우기

    26. 후토시키

    N×N 격자를 1~N으로 채우고 각 행과 열에서 숫자가 겹치지 않게 합니다. 칸 사이에 주어진 부등호를 모두 만족해야 합니다.

    플레이 · 전체 규칙 ↗

  27. 숫자 채우기

    27. 렌조쿠

    각 행과 열에 1~N을 한 번씩 넣습니다. 점으로 연결된 두 칸은 연속된 숫자여야 하고, 점이 없는 인접 칸은 연속된 숫자이면 안 됩니다.

    플레이 · 전체 규칙 ↗

  28. 단어·체스

    28. 단어 찾기 · 보글

    가로·세로·대각선으로 인접한 글자를 연결해 단어를 찾으며, 한 단어에서 같은 칸을 다시 사용할 수 없습니다. 긴 단어일수록 점수가 높고, 난이도별 목표 점수를 달성하면 완료됩니다.

    플레이 · 전체 규칙 ↗

  29. 도형 배치하기

    29. 샤카샤카

    흰 칸 일부에 칸의 절반을 차지하는 검은 직각삼각형을 넣어, 남은 흰 영역을 모두 직사각형이나 정사각형으로 만듭니다. 검은 칸의 숫자는 상하좌우에 인접한 삼각형 수이며, 흰 직사각형은 45° 기울어져도 됩니다.

    플레이 · 전체 규칙 ↗

  30. 숫자 채우기

    30. 카쿠로

    흰 칸에 1~9를 넣어 검은 칸이 지정한 오른쪽·아래쪽 연속 구간의 합을 맞춥니다. 하나의 합계 구간 안에서는 같은 숫자를 반복할 수 없습니다.

    플레이 · 전체 규칙 ↗

  31. 숫자 채우기

    31. 직소 스도쿠

    각 행·열·구역에 같은 숫자가 겹치지 않도록 숫자를 채웁니다. 일반 스도쿠의 직사각형 구역 대신 불규칙한 모양의 구역을 사용합니다.

    플레이 · 전체 규칙 ↗

  32. 숫자 채우기

    32. 킬러 스도쿠

    행·열·구역에 숫자를 중복 없이 넣고, 점선으로 묶인 칸들의 합을 작은 숫자에 맞춥니다. 같은 점선 묶음 안에서도 숫자를 반복할 수 없습니다.

    플레이 · 전체 규칙 ↗

  33. 칸 칠하기

    33. 비나이로

    행·열마다 흑백 개수를 같게 채우고, 같은 색이 세 칸 연속되지 않게 합니다. 행끼리 또는 열끼리 같은 흑백 패턴이 반복되면 안 됩니다.

    플레이 · 전체 규칙 ↗

  34. 칸 칠하기

    34. 노노그램

    행·열의 숫자는 순서대로 이어지는 검은 칸 구간의 길이입니다. 각 구간 사이를 한 칸 이상 비우며 칸을 칠합니다.

    플레이 · 전체 규칙 ↗

  35. 선 연결하기

    35. 슬리더 링크

    칸의 숫자만큼 주변 변에 선을 그려 하나의 닫힌 고리를 만듭니다. 선이 교차하거나 갈라지면 안 됩니다.

    플레이 · 전체 규칙 ↗

  36. 숫자 채우기

    36. 스도쿠

    9×9 격자에 1~9를 채워 각 행·열·3×3 구역에서 모든 숫자가 한 번씩 나오게 합니다.

    플레이 · 전체 규칙 ↗

  37. 도형 배치하기

    37. 라이트업

    전구를 놓아 모든 흰 칸을 밝히되 전구끼리 서로 비추지 않게 합니다. 검은 칸의 숫자는 상하좌우에 붙은 전구 수입니다.

    플레이 · 전체 규칙 ↗

  38. 선 연결하기

    38. 브릿지

    섬의 숫자만큼 가로·세로 다리를 놓아 모든 섬을 하나로 연결합니다. 다리끼리 교차할 수 없고, 한 쌍의 섬 사이에는 최대 두 개를 놓습니다.

    플레이 · 전체 규칙 ↗

  39. 도형 배치하기

    39. 시카쿠

    격자 전체를 직사각형으로 나눕니다. 각 직사각형에는 숫자가 정확히 하나 있고, 넓이는 그 숫자와 같아야 합니다.

    플레이 · 전체 규칙 ↗

  40. 칸 칠하기

    40. 누리카베

    숫자 하나마다 그 숫자 크기의 흰 섬을 만들고, 나머지 검은 칸을 하나로 연결합니다. 서로 다른 섬은 변으로 닿을 수 없고, 검은 2×2도 만들 수 없습니다.

    플레이 · 전체 규칙 ↗

  41. 도형 배치하기

    41. 도미노사

    모든 칸을 가로나 세로로 붙은 두 칸짜리 도미노로 나눕니다. 같은 숫자 조합의 도미노를 중복해서 만들 수 없습니다.

    플레이 · 전체 규칙 ↗
